# Agent Notes

Agent Notes preserve decisions that maintainers may revisit. Store them under `proposed/`, `implemented/`, `rejected/`, or `archived/`, then under one class: `feature`, `bug-fix`, `simplification`, `architecture`, `process`, or `testing`.

Use the `spec-driven-development` Skill and its `references/note-format.md` as the format authority. A non-trivial change requires a proposed or owning implemented note. Rewrite proposal language into current-state decision language before transitioning to `implemented`.
