# Signal Drift

Build a compact Canvas + TypeScript browser game controlled by keyboard. The player keeps a signal aligned while disturbances push it off course. The game needs clear score and lives feedback, pause/resume, restart, responsive rendering, and deterministic game-state logic that can be tested without relying on frame timing. Include automated tests and a production build.

The product owner can answer product questions. Choose reversible implementation details yourself. Deliver source, lockfile, tests, and a short run/verify handoff; do not include dependencies or build output.
