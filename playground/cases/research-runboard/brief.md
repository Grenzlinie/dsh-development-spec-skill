# Research Runboard

Build a polished React + TypeScript single-page dashboard for a small research lab. Members need to see current and recent computational runs, notice failures quickly, search or filter the list, and use the page comfortably on desktop and mobile. Include realistic seeded data, automated tests, and a production build. No backend or authentication is required.

The product owner can answer product questions. Choose reversible implementation details yourself. Deliver source, lockfile, tests, and a short run/verify handoff; do not include dependencies or build output.
